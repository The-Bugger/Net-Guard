Port Scan

A device is probing multiple ports.  This usually indicates reconnaissance.  Recommendations  ✓ Identify the source.  ✓ Check if the scanner is authorized.  ✓ Monitor follow-up attacks.  ✓ Consider blocking repeated scans.

SQL Injection
