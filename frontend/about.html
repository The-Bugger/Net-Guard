About NetGuard

Overview

NetGuard is an Explainable Intrusion Detection and Prevention System (IDPS) built for network security monitoring. It captures live packets, detects five common attack types using configurable rules, generates plain-English explanations for every alert, and optionally blocks malicious IPs via iptables.

Architecture

🦅 Capture Engine

Lives on the wire via Scapy. Decodes TCP, UDP, ICMP, and ARP packets into a normalised internal format. Runs in a daemon thread with clean start/stop semantics.

🧠 Detection Engine

Feeds decoded packets through five parallel detection rules — SYN Flood, Port Scan, SQL Injection, Brute Force, ARP Spoofing. Enforces per-IP cooldowns and sliding time windows.

💬 Explainability Engine

Converts every ThreatEvent into non-expert-friendly text: what happened, why it matters, and what to do. Includes severity, confidence score (0–100), and a concrete recommendation.

🛡 Prevention Engine

Applies iptables DROP rules for blocking IPs. Checks the whitelist first, skips known-good devices. Auto-expires blocks after a configurable duration via a background expiry thread.

🌐 REST API

Flask-based API with 20+ endpoints for monitoring, detections, blocks, whitelist, statistics, logs, settings, and live dashboard data. Uses Flask-SocketIO for real-time push.

📊 Frontend Dashboard

Vanilla JS + Chart.js dashboard with real-time KPI cards, traffic rate chart, severity doughnut, threat timeline with expandable evidence, and management pages for blocks, whitelist, logs, rules, and settings.

Attack Types Detected

AttackRule IDDetection Method
SYN FloodSYN_FLOOD_001TCP SYN rate per source IP within sliding window
Port ScanPORT_SCAN_001Unique (dst_ip, dst_port) pairs per source IP
SQL InjectionSQL_INJECTION_001Regex match on HTTP payload — patterns: ' OR, UNION SELECT, DROP TABLE, --, xp_cmdshell
Brute ForceBRUTE_FORCE_001Auth-failure indicators on ports 22 (SSH), 21 (FTP), 80/443 (HTTP)
ARP SpoofingARP_SPOOF_001Two or more unique MAC addresses claiming the same IP via ARP replies
